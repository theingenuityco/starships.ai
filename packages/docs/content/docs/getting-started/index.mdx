## Prerequisites

Before you begin, ensure you have:

- **Node.js** 18.0 or higher
- **npm** or **yarn** package manager
- A **Starships.ai account** (sign up at [starships.ai](https://starships.ai))
- Basic knowledge of JavaScript/TypeScript
