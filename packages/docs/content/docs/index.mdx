## Quick Start

Get up and running with Starships.ai in three simple steps:

<Steps>
<Step>

### Install the CLI

```bash
npm install -g @starships/cli
# or
curl -fsSL https://get.starships.ai | sh
```

</Step>

<Step>

### Initialize Your Project

```bash
starships init my-agent
cd my-agent
```

</Step>

<Step>

### Deploy Your First Agent

```bash
starships deploy
```

Your agent is now live! 🚀

</Step>
</Steps>
