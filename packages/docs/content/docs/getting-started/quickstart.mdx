## What You'll Be Able To Do

When the CLI is ready, you'll have code-first development capabilities:

```bash
# Install and authenticate
npm install -g @starships/cli
starships login

# Create and develop
starships init my-agent
starships dev

# Deploy to production
starships deploy
```

Perfect for developers who need version control, custom integrations, and automated deployment.

---

## Why Code-First?

- **Version Control**: Track changes and collaborate with teams through Git
- **Advanced Integrations**: Build complex tools and enterprise workflows  
- **Automated Deployment**: CI/CD pipelines and environment management
- **Full Control**: Complete programmatic access to all platform features
