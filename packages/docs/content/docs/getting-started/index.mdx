# Getting Started

Quick setup guide for both conversational and code-first approaches.

## Account Setup

**Required for both approaches:**

1. **Create Account**: Sign up at [starships.ai](https://starships.ai)
2. **Access Dashboard**: Log into your personal starship
3. **Choose Approach**: Select your preferred building method

## Development Prerequisites

**Only required for code-first approach:**

- **Node.js** 18.0 or higher
- **npm**, **yarn**, or **pnpm** package manager  
- Basic **JavaScript/TypeScript** knowledge
- **Git** for version control (optional)
