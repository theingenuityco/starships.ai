# CLI Quickstart

Build agents programmatically using our CLI and SDK.

## Installation

First, install the Starships CLI:

<Tabs items={['npm', 'yarn', 'pnpm']}>
<Tab value="npm">

```bash
npm install -g @starships/cli
```

</Tab>
<Tab value="yarn">

```bash
yarn global add @starships/cli
```

</Tab>
<Tab value="pnpm">

```bash
pnpm add -g @starships/cli
```

</Tab>
</Tabs>

Verify the installation:

```bash
starships --version
```

## Authentication

Log in to your Starships.ai account:

```bash
starships login
```

This will open your browser to authenticate. Once complete, you're ready to build!

## Create Your First Agent

Initialize a new project:

```bash
starships init my-first-agent
cd my-first-agent
```

This creates a project with the following structure:

<Files>
  <Folder name="my-first-agent" defaultOpen>
    <File name="starships.config.ts" />
    <File name="agent.ts" />
    <File name="package.json" />
    <Folder name="tools">
      <File name="example.ts" />
    </Folder>
  </Folder>
</Files>

## Configure Your Agent

Open `agent.ts` and customize your agent:

```typescript title="agent.ts"
import { defineAgent } from '@starships/sdk';

export default defineAgent({
  name: 'my-assistant',
  description: 'A helpful AI assistant',
  model: 'gpt-4-turbo',

  instructions: `
    You are a helpful assistant that can answer questions
    and help users with various tasks.
  `,

  tools: [
    // Add tools here
  ],
});
```

## Test Locally

Run your agent in development mode:

```bash
starships dev
```

Interact with your agent in the terminal:

```bash
starships chat
```

<Callout type="info">
  The `dev` command starts a local server with hot reload. Changes to your agent are applied immediately.
</Callout>

## Deploy to Production

When you're ready, deploy your agent:

```bash
starships deploy
```

You'll receive a unique URL for your agent:

```bash
✓ Deployed successfully!
  URL: https://my-first-agent-abc123.starships.ai
  API: https://api.starships.ai/v1/agents/abc123
```

## Make API Calls

Use your agent via API:

```typescript title="example.ts"
const response = await fetch('https://api.starships.ai/v1/agents/abc123/chat', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer YOUR_API_KEY',
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    message: 'Hello, agent!',
  }),
});

const data = await response.json();
console.log(data.message);
```

## Import to Conversational Interface

```bash
starships import my-first-agent
# Makes your code agent available for conversational editing
```
