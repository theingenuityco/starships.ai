# Problem Statements Implementation Plan

## Overview
Add a new `problemStatements` field to agent templates and agents, following the same architecture as `previewPrompts`. This field will display user-facing problem statements in a 3-step flow on the marketplace agent profile page.

## 3-Step Flow on Agent Profile Page
1. **The Problem** - Problem statements from user's perspective (NEW)
2. **How this agent can solve it** - Capabilities section (existing)
3. **Get started** - Try these prompts section (existing)

## Field Specifications

### Format
- **Type**: Array of strings (like `previewPrompts`)
- **Field name**: `problemStatements`
- **Database storage**: `TEXT[]` array (PostgreSQL)
- **Max items**: 4-5 per agent
- **Content per item**: Mix of:
  - Complete sentences/questions (e.g., "Where do I start?")
  - Short phrases (e.g., "Complex setup process")
  - Full sentences describing pain points (e.g., "Creating a new agent feels overwhelming and time-consuming")

### Display
- **UI format**: Cards (like preview prompts)
- **Section title**: "The Problem"
- **Placement**: Just above Capabilities section
- **Fallback**: If empty, show generic message: "Looking for help with [category]? I can assist you."

### Validation
- Basic validation rules matching patterns in codebase
- Max length per item: ~200 characters (similar to previewPrompts)
- Unique items (case-insensitive)

## Architecture Pattern

### Following `previewPrompts` Pattern
- **Templates (seeders)**: Manually defined in seeders (like `previewPrompts`)
- **User-created agents (via Gaia)**: Auto-generated by Gaia's LLM when creating new agents
- **Existing agents**: Gaia can suggest and update interactively (like it does for `previewPrompts`)

## Migration Strategy

### For Existing Production Agents
- Migration adds column with empty array default (`ARRAY[]::TEXT[]`)
- All existing agents get `[]` initially
- UI shows generic fallback: "Looking for help with [category]? I can assist you."
- Users can ask Gaia to update problem statements interactively (like previewPrompts)
- No backfill script needed - uses Gaia's interactive capabilities

### For New Agents
- Gaia auto-generates `problemStatements` when creating new agents (like `previewPrompts`)
- Gaia can suggest and update problem statements when editing existing agents

### For Templates
- Manually add to seeders over time (like `previewPrompts`)
- Seed script will update existing templates when seeders are updated

## Content Guidelines

### Problem Statement Examples (for reference)
- "Creating a new agent feels overwhelming..."
- "Where do I start?"
- "What tools should I assign?"
- "How do I write a good system prompt?"

### Tone
- Conversational, user-first language
- Empathetic, not negative
- Highlight common frustrations
- Relatable scenarios
