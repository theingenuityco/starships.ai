## Choose Your Path

Select the approach that matches your goals and technical comfort level:

<Tabs items={['Conversational (Recommended)', 'Code-First']}>
<Tab value="Conversational (Recommended)">

**Perfect for**: Getting results fast, business users, rapid prototyping

**What you'll do**: Chat with AI to create agents
**Time to success**: Under 5 minutes
**Technical skill**: None required

```
You: "Create a customer support agent for our SaaS product"
Gaia: "Creating agent with CRM integration, friendly tone, escalation rules..."
Result: Working agent ready immediately
```

**[Start building conversationally →](/core-concepts/agents)**

</Tab>
<Tab value="Code-First">

**Perfect for**: Developers who want full control, complex integrations

**What you'll do**: Write code using CLI and SDK
**Time to success**: 15-30 minutes
**Technical skill**: JavaScript/TypeScript knowledge required

```bash
npm install -g @starships/cli
starships init my-agent
starships deploy
```

**[Start with CLI development →](/getting-started/quickstart)**

</Tab>
</Tabs>

<Callout type="info">
**Can't decide?** Start conversational - you can export to code later. Most users find this path faster and more intuitive.
</Callout>
