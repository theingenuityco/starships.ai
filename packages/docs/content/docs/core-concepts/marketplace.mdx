## What is the Marketplace?

The Marketplace is your gateway to a curated collection of pre-built solutions created by the Starships.ai team and community. Instead of building from scratch, you can:

- **Discover** agents and tools for common use cases
- **Deploy** proven solutions instantly
- **Customize** after deployment to fit your needs
- **Share** your own creations with the community (coming soon)

## Agent Templates

Pre-configured agents ready for immediate deployment across various categories:

### Available Categories

- **💻 Coding**: Development assistants, code review, debugging
- **🎨 Creative**: Content creation, writing, design assistance  
- **📊 Analysis**: Data processing, research, reporting
- **🛠️ Support**: Customer service, help desk, documentation
- **🔗 Integration**: API connectors, workflow automation
- **📈 Automation**: Business process automation, scheduling
- **💬 Communication**: Meeting management, team coordination

## Tool Templates

Reusable workflow components that extend agent capabilities:

### Tool Categories

- **Data Processing**: File manipulation, format conversion
- **External APIs**: Third-party service integrations
- **Calculations**: Mathematical, financial, statistical operations
- **Communication**: Email, notifications, messaging
- **Utilities**: Time, date, formatting helpers
