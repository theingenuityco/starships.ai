## What are Agents?

Agents are AI-powered specialists that work autonomously within your starship. Starships.ai features two primary agents designed for different enterprise needs: **Daedalus** for development and technical workflows, and **Gaia** for business operations and resource management.

## Daedalus - Development Agent

Daedalus is your AI development companion, designed to accelerate software development workflows and automate technical tasks.

### Core Capabilities

<Accordions type="multiple" defaultValue={['development']}>
  <Accordion title="💻 Code Development & Review" value="development">
    **What Daedalus can do:**
    - Review code for bugs, security issues, and best practices
    - Generate code snippets and complete functions
    - Refactor existing code for better performance
    - Create unit tests and documentation
    - Debug complex issues and suggest fixes
    
    **Example tasks:**
    ```
    "Review this React component for performance issues"
    "Generate TypeScript interfaces for this API response"
    "Help me optimize this database query"
    "Create unit tests for the user authentication module"
    ```
  </Accordion>

  <Accordion title="⚙️ Workflow Automation" value="automation">
    **What Daedalus can do:**
    - Set up CI/CD pipelines and deployment workflows
    - Automate testing and quality assurance processes
    - Manage Git operations and version control
    - Create and edit workflow blueprints
    - Monitor system health and performance
    
    **Example tasks:**
    ```
    "Set up a GitHub Actions workflow for automated testing"
    "Create a deployment pipeline for our Node.js app"
    "Help me configure ESLint and Prettier for the project"
    "Design a workflow for code review automation"
    ```
  </Accordion>

  <Accordion title="🔧 DevOps & Infrastructure" value="devops">
    **What Daedalus can do:**
    - Configure Docker containers and orchestration
    - Set up monitoring and logging systems
    - Manage cloud infrastructure and deployments
    - Optimize application performance and scaling
    - Handle security configurations and updates
    
    **Example tasks:**
    ```
    "Help me containerize this application with Docker"
    "Set up monitoring for our production environment"
    "Configure auto-scaling for high traffic periods"
    "Review our security configurations and suggest improvements"
    ```
  </Accordion>
</Accordions>

### Available Tools
- **Code Execution**: Run and test code in sandboxed environments
- **Git Operations**: Version control and repository management
- **Blueprint Editor**: Visual workflow creation and editing
- **API Testing**: HTTP request testing and validation
- **Documentation Generator**: Automated code documentation

## Gaia - Operations Agent

Gaia specializes in business operations, resource management, and organizational optimization across all business functions.

    - Generate reports and insights from data

    - Identify optimization opportunities

    **Example tasks:**
    ```
    "Analyze our Q3 sales performance and identify trends"

    "Generate a monthly operational efficiency report"

  <Accordion title="🎯 Resource Management" value="resources">
    **What Gaia can do:**
    - Optimize team assignments and workload distribution
    - Manage budgets and cost tracking
    - Plan capacity and resource requirements
    - Track inventory and asset utilization
    - Coordinate cross-functional projects
    
    **Example tasks:**
    ```

    "Track project timelines and identify potential delays"

  </Accordion>

  <Accordion title="🔄 Process Optimization" value="optimization">

### Available Tools

- **Resource Planning**: Capacity planning and allocation tools

## Getting Started

Choose the agent that best fits your needs and deploy it to your starship:

<Steps>
<Step>

### Choose Your Agent
**For Development Teams**: Deploy **Daedalus** if you need help with:
- Code review and development
- DevOps and infrastructure automation
- Testing and quality assurance
- Git workflows and CI/CD pipelines

**For Business Teams**: Deploy **Gaia** if you need help with:
- Data analysis and reporting
- Resource planning and optimization
- Process improvement and automation
- Business intelligence and insights

</Step>

<Step>

### Deploy from Marketplace
1. Navigate to your starship's marketplace
2. Find Daedalus or Gaia in the agent templates
3. Click "Deploy" - the agent will be configured automatically
4. Start conversing immediately with your new AI team member

</Step>

<Step>

### Start Working Together
Begin with simple tasks to understand your agent's capabilities:

**For Daedalus:**
```
"Review this code for potential issues"
"Help me set up a testing workflow"
"Generate documentation for this API"
```

**For Gaia:**
```
"Analyze our team's productivity metrics"
"Help me plan resource allocation for next quarter"
"Create a process improvement plan"
```

</Step>
</Steps>

## Agent Collaboration

Both Daedalus and Gaia can work together as a team to handle complex projects:

**Development + Operations**: Daedalus handles the technical implementation while Gaia manages project resources, timelines, and team coordination.

**Example Workflow**:
```
1. Gaia analyzes project requirements and resource needs
2. Daedalus creates technical specifications and development plan
3. Both agents collaborate on implementation and monitoring
4. Gaia tracks progress while Daedalus handles technical issues
```

## Customization

Both agents can be customized to fit your specific needs:

### Basic Configuration
- **Personality**: Adjust communication style (formal, casual, technical)
- **Tools**: Enable/disable specific capabilities based on your requirements
- **Performance**: Optimize for speed vs. detailed responses

### Enterprise Features
- **Access Controls**: Role-based permissions and team management
- **Integration**: Connect to your APIs, databases, and existing tools
- **Monitoring**: Track usage, performance, and business impact
- **Security**: Enterprise-grade encryption and compliance controls

<Callout type="info">
  **Getting Started**: Both Daedalus and Gaia come pre-configured with optimal settings. You can start using them immediately and customize later as needed.
</Callout>
