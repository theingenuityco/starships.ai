## What Are Agents?

**Agents** are AI assistants that combine language understanding, tool usage, and memory. Unlike simple chatbots, agents can:

- **Take Actions**: Use tools to interact with systems and data
- **Remember Context**: Maintain conversation history and preferences
- **Execute Workflows**: Follow multi-step processes with decision making
- **Collaborate**: Work with humans and other agents

Think of agents as **AI teammates** that work independently within defined boundaries.

---

## Universal Agent Architecture

Every agent in the Starships.ai framework shares the same core architecture:

### Core Components

- **<Brain className="inline w-4 h-4" /> Personality**: System prompt defining expertise, communication style, and behavioral guidelines
- **<Wrench className="inline w-4 h-4" /> Tools**: Set of capabilities like API calls, data processing, file operations, integrations  
- **<Database className="inline w-4 h-4" /> Memory**: Persistent context including conversation history, user preferences, and learned patterns
- **<Workflow className="inline w-4 h-4" /> Blueprints**: Workflow definitions that specify how the agent executes multi-step tasks
- **<Settings className="inline w-4 h-4" /> Configuration**: Model selection, permissions, timeout settings, and operational parameters

## The Universal Agent Blueprint

Every agent follows the same core execution pattern:

```mermaid
graph TD
    START([start]) --> LLM[llm: AI Processing]
    LLM --> CHECK{conditional: Has Tool Calls?}
    
    CHECK -->|No Tool Calls| END([end: Return Response])
    CHECK -->|Has Tool Calls| ARGS[code: Prepare Arguments]
    
    ARGS --> TOOL[tool: Execute Function]
    TOOL --> RESULT[mutate: Add Tool Result]
    RESULT --> LLM
    
    style START fill:#e8f4fd,stroke:#1e40af,stroke-width:2px,color:#1e40af
    style END fill:#e8f4fd,stroke:#1e40af,stroke-width:2px,color:#1e40af
    style LLM fill:#f0f9ff,stroke:#0369a1,stroke-width:2px,color:#0c4a6e

    style ARGS fill:#f3f4f6,stroke:#6b7280,stroke-width:2px,color:#374151
    style TOOL fill:#ecfdf5,stroke:#059669,stroke-width:2px,color:#065f46
    style RESULT fill:#f0f9ff,stroke:#0284c7,stroke-width:2px,color:#0c4a6e
```

### How Each Node Works

- <span style={{color: '#0066cc'}}>**[start](/core-concepts/blueprints#start-node)** <ExternalLink className="inline w-3 h-3" /></span>: Receives input and triggers agent execution
- <span style={{color: '#0066cc'}}>**[llm](/core-concepts/blueprints#llm-node)** <ExternalLink className="inline w-3 h-3" /></span>: Processes requests using AI models, decides on tool usage  
- <span style={{color: '#0066cc'}}>**[conditional](/core-concepts/blueprints#conditional-node)** <ExternalLink className="inline w-3 h-3" /></span>: Routes execution based on LLM decisions (tools vs. response)
- <span style={{color: '#0066cc'}}>**[code](/core-concepts/blueprints#code-node)** <ExternalLink className="inline w-3 h-3" /></span>: Prepares data and formats tool arguments for execution
- <span style={{color: '#0066cc'}}>**[tool](/core-concepts/blueprints#tool-node)** <ExternalLink className="inline w-3 h-3" /></span>: Executes capabilities like API calls, data processing
- <span style={{color: '#0066cc'}}>**[mutate](/core-concepts/blueprints#mutate-node)** <ExternalLink className="inline w-3 h-3" /></span>: Updates memory with tool results for next LLM cycle
- <span style={{color: '#0066cc'}}>**[end](/core-concepts/blueprints#end-node)** <ExternalLink className="inline w-3 h-3" /></span>: Returns response when agent has complete answer

## How Agents Process Requests

### The Tool-Calling Loop
What makes agents intelligent rather than just chatbots:

<Steps>
<Step icon={<Brain />}>
### LLM Analyzes Request
The AI model examines your input and compares it against available tools and conversation history
</Step>

<Step icon={<Zap />}>
### Decides on Action
Either provides a direct response or identifies which tools are needed to gather more information
</Step>

<Step icon={<Wrench />}>
### Executes Tools
Calls external APIs, searches databases, processes files, or performs calculations as needed
</Step>

<Step icon={<RotateCcw />}>
### Incorporates Results
Adds tool results to its understanding and repeats until it can provide a complete answer
</Step>
</Steps>

**Example Flow**:
```
User: "What's our team's progress this week?"

Agent thinks: "I need project data" → Calls project-status tool
Tool returns: Current task completion rates
Agent thinks: "I need recent updates" → Calls team-activity tool  
Tool returns: This week's commits and updates
Agent responds: "Your team completed 12 tasks this week, 3 ahead of schedule..."
```

### Why This Works
- **Self-contained**: Each agent has AI model + tools + memory
- **Purpose-built**: Same architecture, different tools = different capabilities  
- **Composable**: Agents can work together on complex workflows
- **Learning**: Every interaction improves decision-making

## Agent Memory

Agents maintain context across conversations:

- **Remember what you've discussed** and your preferences
- **Adapt to new capabilities** when tools are added
- **Share context** with other agents when working together

This persistent memory is what makes agents intelligent teammates rather than simple chatbots.

### Enterprise Integration
