## What's Coming

When code-first development is ready, you'll find detailed installation instructions here for:

### CLI Package
- **Global installation**: `npm install -g @starships/cli`
- **Authentication**: `starships login`  
- **Project scaffolding**: `starships init my-agent`
- **Local development**: `starships dev`
- **Deployment**: `starships deploy`

### SDK Integration
- **JavaScript/TypeScript SDK**: For custom integrations
- **Agent definition APIs**: Programmatic agent creation
- **Tool development kit**: Build custom tools with code
- **Blueprint editor**: Visual workflow builder
- **Local testing**: Development environment setup

### Development Prerequisites
- **Node.js** 18.0 or higher
- **npm**, **yarn**, or **pnpm** package manager  
- Basic **JavaScript/TypeScript** knowledge
- **Git** for version control (optional)
