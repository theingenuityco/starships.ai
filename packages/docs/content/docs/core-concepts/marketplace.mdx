## One-Click Deployment

<div className="my-6">
  <img
    src="/docs/images/agent_deploy.png"
    alt="Deployment confirmation modal showing template details, destination starship, and model information before deployment"
    className="w-2/3 mx-auto rounded-lg border border-border/20 shadow-lg"
  />
  <div className="text-sm text-muted-foreground text-center mt-2">
    Deployment confirmation: Review template details and destination before one-click deployment
  </div>
</div>

Deployment is simple and automatic:

1. **Select Template** → Review capabilities and requirements
2. **Confirm Deployment** → Verify template, starship, and model details
3. **Automatic Installation** → Template converts to active instance, tools install automatically
4. **Ready to Use** → Instant availability with optimal settings

**Behind the Scenes**: Templates deploy with modular design, automatic dependency management, rollback protection, and security validation.

### <Bot className="inline w-5 h-5" /> Agent Templates

**Complete AI assistants** with personality, memory, and capabilities. Deploy as conversational interfaces you can chat with immediately. Learn more about [how agents work](/core-concepts/agents).

**Includes**: System prompt, model configuration, tool suite, memory setup, example prompts  
**Result**: New agent in your starship ready for conversation

### <Wrench className="inline w-5 h-5" /> Tool Templates

**Standalone capabilities** that extend agent functionality. Install once, use across multiple agents. Explore the [tool ecosystem](/core-concepts/tools).

**Includes**: Function definition, configuration schema, usage examples, integration guides  
**Result**: New tool in your library, assignable to any agent
