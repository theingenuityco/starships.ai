# Blueprints

The visual workflow definition language that powers agent execution and multi-step task automation.

<Callout type="success">
  **Visual Programming**: Blueprints provide a node-based approach to defining complex agent workflows without traditional coding.
</Callout>

## What Are Blueprints?

**Blueprints** are visual workflow definitions that specify how agents execute multi-step tasks. They consist of interconnected nodes that define:

- **Data flow** between processing steps
- **Decision logic** for conditional branching
- **Tool execution** for external integrations
- **State management** for persistent data
- **Error handling** for robust workflows

Think of blueprints as **visual programs** that agents follow to accomplish complex tasks.
