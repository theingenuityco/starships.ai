# CLI Quickstart

<Callout type="warning" title="Coming Soon">
CLI package for programmatic agent creation is in active development and will be available soon.
</Callout>

Build agents programmatically using our CLI and SDK - perfect for developers who want full control and integration capabilities.

---

## What You'll Be Able To Do

When the CLI is ready, you'll have powerful code-first development capabilities:

### Installation
```bash
npm install -g @starships/cli
```

### Authentication
```bash
starships login
```
This will open your browser to authenticate with your Starships.ai account.

### Create Your First Agent
```bash
starships init my-first-agent
cd my-first-agent
```

### Project Structure
```
my-first-agent/
├── starships.config.ts    # Project configuration
├── agent.ts              # Agent definition
├── package.json          # Dependencies
└── tools/               # Custom tools
    └── example.ts
```

### Agent Definition
```typescript title="agent.ts"
import { defineAgent } from '@starships/sdk';

export default defineAgent({
  name: 'my-assistant',
  description: 'A helpful AI assistant',
  model: 'anthropic/claude-sonnet-4.5',

  instructions: `
    You are a helpful assistant that can answer questions
    and help users with various tasks.
  `,

  tools: [
    // Add tools here
  ],
});
```

### Local Development
```bash
starships dev        # Start local development server
starships chat       # Test your agent in terminal
```

### Deploy to Production
```bash
starships deploy
```

### Import to Conversational Interface
```bash
starships import my-first-agent
# Makes your code agent available for conversational editing
```
