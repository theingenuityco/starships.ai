## One-Click Deployment: From Template to Running Agent

  <img

### The Deployment Process

**Step 1: Template Selection**
- Browse or search for the perfect template
- Review capabilities and requirements
- Check deployment status on your starship

**Step 2: Deployment Confirmation**
- **Template Preview**: Confirm you're deploying the right template
- **Starship Selection**: Choose destination (auto-detects your primary starship)
- **Requirement Check**: Verify any API keys or configuration needed
- **Model Information**: Confirm AI model and pricing implications

**Step 3: Automatic Installation**
- **Template Conversion**: Transform template into active instance
- **Tool Deployment**: Automatically install required tools
- **Relationship Setup**: Link agent to tools and configure permissions
- **Initial Configuration**: Apply default settings and preferences

**Step 4: Ready to Use**
- Instant availability in your starship
- Pre-configured with optimal settings
- Ready for customization and training

### Behind the Scenes: Template Architecture

### Smart Template System
- **Modular Design**: Agents and tools deploy independently
- **Dependency Management**: Required tools installed automatically
- **Version Control**: Templates maintain compatibility and updates
- **Resource Optimization**: Shared tools across multiple agents

### Enterprise-Grade Deployment
- **Rollback Protection**: Failed deployments don't affect existing agents
- **Permission Management**: Proper access controls from day one
- **Usage Tracking**: Monitor template performance and usage
- **Security Validation**: All templates undergo security review

## Agent vs Tool Templates: Understanding the Difference

<div className="my-6">
  <img 
    src="/docs/images/marketplace_tools.png" 
    alt="Tools marketplace section showing automation tools with code examples and installation status" 
    className="w-full rounded-lg border border-border/20 shadow-lg"
  />
  <p className="text-sm text-muted-foreground text-center mt-2">Tool templates: Reusable capabilities with code examples and one-click installation</p>
</div>

### Agent Templates

**What They Are**
- Complete AI assistants with personality, memory, and capabilities
- Include system prompts, model configuration, and tool assignments
- Deploy as conversational interfaces you can chat with immediately

**What's Included**
- **<Brain className="inline w-4 h-4" /> Personality**: System prompt defining expertise and behavior
- **<Bot className="inline w-4 h-4" /> Model Configuration**: AI model selection and parameters
- **<Wrench className="inline w-4 h-4" /> Tool Suite**: Pre-configured tools for specific capabilities
- **<Database className="inline w-4 h-4" /> Memory Setup**: Context management and conversation history
- **<MessageSquare className="inline w-4 h-4" /> Example Prompts**: Starter conversations and use cases

**Deployment Result**
- New agent appears in your starship's agent list
- Immediately available for conversation
- Pre-configured with optimal settings
- Tools automatically available and linked

### Tool Templates

**What They Are**
- Standalone capabilities that extend agent functionality
- Reusable workflow components with specific purposes
- Install once, use across multiple agents

**What's Included**
- **<Settings className="inline w-4 h-4" /> Function Definition**: Specific capability (API call, calculation, etc.)
- **<Code className="inline w-4 h-4" /> Configuration Schema**: Required settings and API keys
- **<Package className="inline w-4 h-4" /> Usage Examples**: Code snippets and integration patterns
- **<ExternalLink className="inline w-4 h-4" /> Integration Guides**: How to use with different agents

**Deployment Result**
- New tool appears in your starship's tool library
- Available for assignment to any agent
- Configurable through settings interface
- Reusable across multiple workflows
